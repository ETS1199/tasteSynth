How we do it

TasteSynth uses the Spotify API to access your playlists and create new synthesized ones with your permission.

What you need to do

For each playlist you'd like to synthesize, you need to be either a collaborator or an owner.

If you're not a collaborator on the playlist, the owner needs to add you as one:

  1. Open the playlist and click the ... option.
  2. Select Invite collaborators, which brings up an invite pop-up.
  3. Choose whichever method you like to send the invite from the pop-up.
